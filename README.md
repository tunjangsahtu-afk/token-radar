Token Radar ranks pre-token protocols by their implied launch value and shows how to farm each one, in a web dashboard. It reads a sealed DefiLlama snapshot, applies a strict no-wrapped-product rule, and ranks 178 protocols with a 7-step farm plan each.

## Run it

```sh
node main.ts
```
